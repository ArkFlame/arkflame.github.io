## What it does

HubCombat adds PvP and weapons to a lobby server. It targets Paper 1.21.7 with Java 21 and exposes a reload command plus an admin permission.

## Highlights

- Lobby PvP and weapons.
- Paper 1.21.7 build.
- Reload command and admin permission.

## Compatibility

- Platforms: Paper.
- Minecraft version: Paper 1.21.7.
- Java: Java 21.
- Folia: not stated in the repository.

Verify the version and Folia claims on your own server before you rely on them.
