## What it does

FlamePearls corrects ender-pearl movement glitches and supports limiting stasis chambers. Behaviour is controlled from a single config file.

## Highlights

- Ender-pearl glitch fixes.
- Stasis-chamber limiting.
- Single config file.

## Compatibility

- Platforms: Bukkit, Spigot.
- Minecraft version: No version range stated in the repository.
- Folia: declared in the repository.

Verify the version and Folia claims on your own server before you rely on them.
